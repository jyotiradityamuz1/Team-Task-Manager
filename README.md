# 🚀 Team Task Management System (MERN)

A full-stack web application designed to help teams manage projects, assign tasks, and track progress efficiently. This system enables seamless collaboration with secure authentication and role-based access control.

---

## 📌 Features

* 🔐 User Authentication (JWT-based login & signup)
* 📂 Create, update, and delete projects
* ✅ Assign tasks and track status (To-Do, In Progress, Completed)
* 🔍 Search users and assign multiple members to tasks
* 🛡️ Role-based access control (only project creators can delete)
* ⚡ Dynamic UI with real-time updates

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/task-manager.git
cd task-manager
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Run backend server:
npm run dev



### 3️⃣ Frontend Setup


cd frontend
npm install
npm run dev
